Política de Privacidade

Última atualização: 5 de novembro de 2026.

Esta política se aplica à ferramenta Claude Analytics Leonardo, de uso próprio de Leonardo Magalhães.

Dados acessados

Com a autorização da conta usada no login, a ferramenta consulta dados de marketing e de desempenho das contas a que essa pessoa já tem acesso, como relatórios do Google Analytics, Search Console, Tag Manager, Google Ads e Merchant Center.

Como os dados são usados

Os dados são usados somente para gerar análises e relatórios de marketing dessas contas. Eles podem ser processados pelo assistente de inteligência artificial Claude, da Anthropic, para produzir essas análises.

Armazenamento

As credenciais de acesso e os relatórios ficam no computador de Leonardo Magalhães. A ferramenta não mantém um banco de dados público.

Compartilhamento

Os dados não são vendidos nem usados para publicidade. Eles só são compartilhados com os serviços necessários para gerar as análises e com as pessoas responsáveis pelas contas analisadas.

Dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
